# Keep Plugin Data local-first with optional Core Sync

Plugins remain usable offline and own their Plugin Data locally, while a future opt-in Core Sync service may synchronize data that a Plugin explicitly marks as eligible. Core Sync standardizes encrypted transport, backup, schema versions, conflict handling, and restoration without absorbing data ownership; Plugins may still use their own cloud services through Network Permissions. This postpones cross-device convenience but avoids making network availability or a Corelib account prerequisites for everyday functions.
