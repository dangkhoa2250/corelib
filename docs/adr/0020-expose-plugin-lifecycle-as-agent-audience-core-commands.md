# Expose Plugin lifecycle as Agent-audience Core Commands

Corelib exposes enable, disable, pin, unpin, and reorder operations as versioned Core Commands discoverable by the Agent audience but hidden from the human Command Palette. The commands delegate to the same `PluginLifecycle` plan and apply path as Corelib Home, and disable or cascade plans retain execution-time confirmation requirements; Phase 2 supplies the contract and authorized execution seam without implementing an Agent model, Agent UI, grants, or autonomous authority.
