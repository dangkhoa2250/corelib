# Review and sign Marketplace Plugins

Plugin Publishers may submit Plugins to the Plugin Marketplace, but a submitted version is not available to Library users until Corelib has reviewed and signed it. Library accepts Marketplace installations only when the Plugin version carries a valid Corelib signature; local development may allow unsigned Plugins through an explicit developer-only mode. This trades immediate open publication for a safer default around personal documents, learning data, credentials, and future Plugin capabilities.
